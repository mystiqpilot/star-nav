# Security policy

Please report security problems privately through GitHub's "Report a vulnerability"
(Security tab → Advisories) rather than in a public issue. Include the app version, the
build (`foss` or `play`) and steps to reproduce.

Relevant areas: anything that could make the app serve a wrong position without showing
it, leak recordings or identifiers outside the user's explicit export, or let another app
on the phone control the mock output.

Only the latest release is supported with fixes.
